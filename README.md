NEONCORE — Gamer Sign-Up Form

A responsive gamer registration form built for the NEONCORE competitive gaming network.

About the Project

NEONCORE is a front-end practice project focused on creating a modern gaming sign-up experience with form validation, interactive password controls, and responsive design.

Features

- Responsive layout for desktop and mobile devices
- Callsign and email input fields
- Password and confirm-password fields
- Show/hide password functionality
- Password length validation
- Form validation with clear error messages
- Terms and privacy agreement checkbox
- Loading state and success feedback
- Keyboard accessibility support

Built With

- HTML5
- CSS3
- JavaScript

Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No additional dependencies are required for this front-end project.
